# The Next Move — Website

A polished Next.js starter for **The Next Move**, a coaching programme by Ayomikun Oluwaseun Aluko.

## What is included

- Public landing page
- About / coach page
- Programme page
- Login, registration and password reset screens
- Student dashboard
- Six-module course map
- Lesson experience
- Workbook area
- Community area
- Profile area
- Responsive design
- Local/mock data architecture ready for Supabase or another backend

## Run locally

Requirements: Node.js 20+

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deploy to Vercel

1. Create a GitHub repository and push this project.
2. Import the repository into Vercel.
3. Keep the default Next.js build settings.
4. Deploy.

No environment variables are required for this starter.

## Next production upgrades

The UI intentionally uses local/mock data so the site can be previewed immediately. For the real course platform, add:

- Supabase Auth
- Course/module/lesson tables
- User progress
- Secure video hosting
- Workbook file storage
- Payment integration
- Community moderation
- Email onboarding
- Admin/content-management area

The visual system is deliberately independent of the reference site: it takes inspiration from a warm, editorial learning-community feel without copying another site's branding or content.
